# 🎲 Probability Playground

An interactive, visual web application designed for students and educators to explore probability, randomness, sampling variability, and statistical convergence.

## Project Structure
- `app.py`: Streamlit application code.
- `requirements.txt`: Python package dependencies.
- `README.md`: Project documentation and setup guide.

## Features
- **Coin Toss Simulations & Law of Large Numbers**: Watch experimental probabilities converge to theoretical values in real-time.
- **Single & Double Dice Rolls**: Compare empirical bar charts with expected theoretical distributions (1d6 and 2d6).
- **Card Draws & Combinatorics**: Investigate standard deck probabilities and sampling.
- **Sampling Variability & CLT**: Explore how sample means distribute around population parameters.
- **Interactive Quizzes**: Test knowledge with instant feedback and pedagogical explanations.
- **Teacher Resources**: Access lesson objectives, activity ideas, and downloadable curriculum guides.

## Local Setup
1. Unzip the project archive.
2. Open a terminal in the project directory.
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Launch the application:
   ```bash
   streamlit run app.py
   ```
